# Curt Reyes Portfolio

A responsive developer portfolio built with React, Vite, and plain CSS.

## Requirements
- Node.js (LTS)
- VS Code (recommended)

## Run locally
1. Extract the ZIP.
2. Open the `curt-portfolio` folder in VS Code.
3. Open Terminal in VS Code.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (typically http://localhost:5173).

## Before publishing
- Replace `YOUR_EMAIL_HERE` in `src/main.jsx` with your actual email.
- Update the LinkedIn URL.
- Add actual project screenshots if available.
- Check descriptions and tech stacks for accuracy.
- Consider removing credentials or secrets from any showcased repositories.

## Build
```bash
npm run build
```
